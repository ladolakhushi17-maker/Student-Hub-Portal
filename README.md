# StudentHub Portal

StudentHub is a web-based student portal designed to provide students with easy access to academic information, attendance, assignments, courses, notices, faculty details, and other student services.

## Project Objective

The main objective of StudentHub is to create a simple and user-friendly portal where students can manage and access their academic information from one place.

## Features

- Student Registration
- Student Login
- Forgot Username
- Forgot Password
- Student Profile
- Course Information
- Attendance Details
- Assignment Information
- Faculty Information
- College Notices
- Timetable
- Contact Us
- Admin Panel
- Easy Navigation Between Pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub
